🤖 Agent IA

Validation Automatique de Recettes Fibre Optique

Une solution intelligente pour automatiser la création et la validation de formulaires techniques dans le secteur des télécommunications

⚠️

📚
Normes Complexes

Centaines de pages de documentation technique à connaître par cœur

✅ Notre Solution : Agent IA en 2 Modules

📝 Module 1 : Générateur de Formulaires

generate_schema.py → Lit les normes techniques (normes_telecoms.txt) → Génère automatiquement un formulaire JSON → Inclut les valeurs de référence et instructions

🔍 Module 2 : Validateur Intelligent

analyze_form.py → Analyse les données mesurées → Compare avec les normes FTTx/ARCEP → Produit un rapport de conformité détaillé

💡 Exemple Concret de Validation

📊 Données Mesurées :

Atténuation moyenne : 0.45 dB/km Réflectance (ORL) : -45 dB Perte par connecteur : 0.5 dB

🤖 Résultat de l'Agent IA :

❌ NON CONFORME : Atténuation (0.45 dB/km) dépasse le seuil max de 0.35 dB/km par 0.10 dB/km ❌ NON CONFORME : Réflectance (45 dB) est trop faible. La norme FTTx exige >= 55 dB ❌ NON CONFORME : Perte par connecteur (0.5 dB) est trop élevée. Max autorisé : 0.3 dB (Norme ARCEP)
